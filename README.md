## 📌 Featured Project: SQL Server Backup Restore Tool

A Python-based automation tool that restores SQL Server databases (Full, Differential, Log) using **LSN-based chain detection** and **STANDBY mode** for log shipping scenarios.

🔗 [View Project →](https://github.com/AbazarKord/SQLRestoreManager)

### ✨ Key Features
- 🔍 Scans `.bak` and `.trn` files in a directory
- 📊 Extracts `FirstLSN`, `LastLSN`, `DatabaseBackupLSN` using `RESTORE HEADERONLY`
- 🧩 Sorts backups by LSN chain to find the correct restore order
- 📡 Restores in **STANDBY** mode (online, read-only) for continuous log shipping
- 💾 Tracks the last restored LSN in a text file for seamless continuation
- ⚙️ Handles broken chains, missing files, and access issues
